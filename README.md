# AI OFFICE v0.4.0 · Project Manager

AI API 추가 과금 없이 사용자가 로그인한 ChatGPT / Claude / Gemini 구독 웹 세션을 AI 직원에게 배정하는 Electron 데스크톱 앱입니다.

## v0.4 핵심
- 프로젝트 생성
- 프로젝트별 팀장 지정
- 참여 직원의 역할을 기준으로 하위 업무 자동 생성
- 직원 업무가 끝나면 팀장 최종 취합 업무 자동 생성
- 프로젝트 진행률과 상태 표시
- 업무 수정 / 개별 삭제
- 완료 업무 일괄 삭제 / 전체 업무 삭제
- 작업 중 업무 삭제 시 늦게 도착한 자동응답 무시
- 기존 구독 웹 자동화 및 수동 폴백 유지
- 유료 API 호출 없음

## 실행
기존 설치 사용자는 앱의 `업데이트 & 재시작` 버튼을 사용하세요.

## 프로젝트 흐름
CEO 목표 → 직원별 역할 업무 → 직원 보고 → 팀장 최종 취합 → CEO 보고함

## 주의
구독 웹 자동화는 각 서비스의 현재 웹 UI와 로그인 상태에 영향을 받는 실험 기능입니다. 자동화 실패 시 기존 수동 `AI 열기 / 프롬프트 복사 / 결과 입력` 방식으로 계속 사용할 수 있습니다.
