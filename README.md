# AI OFFICE v0.3.0 · Subscription Automation

AI API를 사용하지 않고, 사용자가 로그인한 ChatGPT / Claude / Gemini 구독 웹 세션을 직원에게 배정하는 Electron 데스크톱 앱입니다.

## v0.3 핵심
- 업무 배정 즉시 자동 실행 옵션
- 서비스별 작업 큐: 같은 서비스는 순차 처리, 서로 다른 서비스는 병렬 처리 가능
- 구독 AI 입력창 자동 탐색 및 프롬프트 전달 시도
- 응답 완료 감지 및 CEO 보고함 자동 저장 시도
- 자동화 실패 시 기존 수동 `AI 열기 / 프롬프트 복사 / 결과 입력` 유지
- API 키 및 유료 API 호출 없음

## 실행
기존 설치 사용자는 `UPDATE_AND_RUN.bat` 또는 앱의 `업데이트 & 재시작` 버튼을 사용하세요.

## 주의
구독 사이트의 UI/로그인/사용량 제한은 각 서비스 정책과 현재 웹 구조에 따라 달라질 수 있습니다. v0.3 자동 전달/회수는 웹 UI 변화에 영향을 받는 실험 기능입니다.
